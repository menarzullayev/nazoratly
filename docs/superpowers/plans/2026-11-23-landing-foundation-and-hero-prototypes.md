# Landing: foundation, language engine, hero prototypes. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Owner rule: no subagents unless asked, so executing-plans in the main session.)

**Goal:** Build `web/` (Next.js static site) with the 5-version Uzbek/Russian/English language engine and three hero-scene prototypes at a non-indexed `/lab`, served on the live domain next to the API, so the owner can pick one hero.

**Architecture:** Monorepo folder `web/`, Next.js 16 App Router with `output: "export"`; copy in typed dictionaries (`uz` Latin source, hand-written `ru`/`en`), Cyrillic and new-Latin generated by a pure tested transliterator; Three.js scenes behind a capability gate with a no-WebGL fallback; nginx container + Cloudflare path routing.

**Tech Stack:** Next.js 16.4.x, React 19, TypeScript strict, Tailwind v4, GSAP + ScrollTrigger, Lenis, three + @react-three/fiber + drei, Vitest, Playwright, nginx.

**Spec:** `docs/superpowers/specs/2026-11-23-landing-page-design.md`

## Global Constraints

- No GitHub link and no words "open source" / "ochiq kod" anywhere on the page.
- No third-party requests at runtime (self-hosted fonts, no analytics, no CDN); CSP-friendly (no inline scripts except Next's hashed ones; verify at build).
- No invented customers, testimonials, statistics, logos. Payme/Click/SMS/fiscalization are NOT advertised.
- Contacts allowed on the page: `@menarzullayev`, `+998902336600`, `@nazoratlybot`.
- Locales and URLs: `/` uz-Latn (default), `/uz-cyrl`, `/uz-new`, `/ru`, `/en`. `x-default` = `/`.
- New Latin: `o'`→`ö`, `g'`→`ğ`, `sh`→`ş`, `ch`→`ç`, `ng` spelled unchanged, tutuq `'` kept (rules from news reports on the law of 2026-10-21; re-verify against lex.uz before release).
- `prefers-reduced-motion` and no-WebGL must still give a complete, readable page.
- Demo math must import `sheets/src/domain/*` (no copies). (Used from the next plan; alias set up here.)
- Existing API behaviour (`/v1`, `/pay`, `/hooks`, `/health`, `/ready`) must not change.

## Review Focus

- Apostrophe variants in Uzbek source (`'`, `‘`, `’`, `ʻ`, `ʼ`): all must transliterate identically (Task 2).
- WebGL unavailable, context lost, or GPU blocklisted: page keeps working with the fallback scene (Tasks 5-8).
- JavaScript disabled or slow: all text is in the static HTML and readable (Task 3).
- 320 px wide screen and 200% zoom: no horizontal scroll (Task 3 smoke test).
- Unknown path or locale (`/de`, `/uz-latn`): the 404 page renders and tunnel does not send it to the API (Tasks 3, 9).

### Task 2: Transliterator (Uzbek Latin to Cyrillic and new Latin)

**Files:**
- Create: `web/lib/translit/index.ts`, `web/lib/translit/cyrillic.ts`, `web/lib/translit/newLatin.ts`, `web/lib/translit/normalize.ts`
- Test: `web/test/translit.test.ts`

**Interfaces:**
- Produces: `normalizeApostrophes(s: string): string` (maps `‘ ’ ʻ ʼ` to ASCII `'`), `toNewLatin(s: string): string`, `toCyrillic(s: string): string`, `type UzScript = "latn" | "cyrl" | "new"`, `convert(s: string, to: UzScript): string`.

- [ ] **Step 1: Write failing tests** with exact expectations. New Latin: `toNewLatin("O'zbekiston") === "Özbekiston"`, `"g'oya"→"ğoya"`, `"shahar"→"şahar"`, `"choy"→"çoy"`, `"tong"→"tong"` (ng unchanged), `"ma'no"→"ma'no"` (tutuq kept), `"Sh"/"SH"` capitals → `"Ş"/"Ş"`, `"mas'ul"` unchanged. Cyrillic: `"O'zbekiston"→"Ўзбекистон"`, `"g'oya"→"ғоя"`, `"shahar"→"шаҳар"` (`sh`→`ш`, lone `h`→`ҳ`), `"choy"→"чой"`, `"ng"→"нг"`; the test file holds the full mapping table as the rule source. Also `"yo'q"→"йўқ"`, `"ye"/"yo"/"yu"/"ya"` word-initial `е/ё/ю/я`, `"ts"→"ц"`, `"ma'no"→"маъно"`. Apostrophe variants (`‘ ’ ʻ ʼ`) give identical output to `'`. Idempotence: converting already-converted text leaves it unchanged. Non-letters (digits, `+998`, URLs, `@nazoratlybot`, HTML tags) untouched: `convert("@nazoratlybot", "cyrl") === "@nazoratlybot"`.
- [ ] **Step 2: Run** `npx vitest run test/translit.test.ts`. Expected: FAIL (module missing).
- [ ] **Step 3: Implement** `normalize.ts`, `newLatin.ts` (ordered digraph replacement, case-aware, protect `s'h`/`n'g` splits) and `cyrillic.ts` (standard mapping; `e` after consonant = `е`, word-initial `e` = `э`; `'`→`ъ` between letters). Protected tokens: anything inside `<...>`, URLs, `@handles`, digits, and `{{placeholders}}` pass through.
- [ ] **Step 4: Run** the test file and `npm run typecheck`. Expected: PASS.
- [ ] **Step 5: Commit** `feat(web): Uzbek script transliterator with tests`.
