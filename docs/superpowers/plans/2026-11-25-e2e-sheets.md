# E2: Sheets end-to-end flows and manifest/scope audit

Branch `e2-e2e-sheets`. Area: `sheets/test/e2e/`, `sheets/test/harness.ts` (additive counters), fixes in `sheets/src`, `tests/golden/` only if a money rule lacks cases. Nothing in `backend/src` or `web/`.

## 1. Audit (`sheets/test/e2e/audit.test.ts`)
- Scan every `sheets/src/**/*.ts` (comments stripped) for runtime Apps Script globals (SpreadsheetApp, DriveApp, UrlFetchApp, ScriptApp, Session, HtmlService, LockService, PropertiesService, CacheService, Utilities, ContentService, ...) and the members called.
- A table maps service/member to the OAuth scopes that satisfy it (Google's documented authorization per method). An unknown `*App` / `*Service` global or member fails the test, so a new service forces a scope decision.
- Needed scopes must all be in `sheets/appsscript.json`; every declared scope must be justified by some use (nothing superfluous); `urlFetchWhitelist` must cover every fetched host.
- Every `addItem(label, fn)` in Code.ts points to a registered handler; every `google.script.run` target used by `src/ui/*.html` exists; every HTML file loaded by HtmlService exists and is built by `build.mjs`.
- Every `ALL_TABLES` sheet exists after setup with its header row, a warning-only header protection, ledger sheets with script-only sheet protection; setup twice changes nothing (cells, protections, triggers, properties).

## 2. E2E journeys (`sheets/test/e2e/*.test.ts`, in-memory harness, menu level)
Helper `drive(menuFn, ...promptAnswers)` sets the prompts, calls the registered handler, returns the alerts. Journeys: setup + students/groups/enroll + attendance, billing (4 discount kinds, partial payment, refund variants, cash close), journal verify + tamper, period close + reports, schedule, growth, results, AI rule reports, branches, guardian + teacher owner side, import with bad rows, QR, waitlist, demo clear/refresh.

## 3. Parity
For every money rule with a golden file, check that the Sheets golden test reads it; add missing cases to `tests/golden/*.json` (and the minimal Python reader) only if a money rule is uncovered.

## 4. Quota guard
2000 students, 24 months of journal through the harness; per-action read/write call budget (counters in the harness). Fails when an action exceeds its budget.

## 5. Bugs
Real bugs go into separate commits with regression tests and are listed in the PR.

Checks: `cd sheets && npm test && npm run build && npx tsc --noEmit`; backend golden test if golden JSON changes.
